01

The redesign brought new screens and left old components behind.

Before designing the system, I mapped what was breaking.

So+ma is an app where people recycle, earn points and trade them for rewards or donate. I reviewed the redesign in FigJam, screen by screen, and noted everything that did not hold up.

146 notes across 6 areas of the app

Sign-up and onboarding45
Search for a material35
Home, invites, donations and balance32
My rewards16
My impact11
Quiz7

Six examples of what came up

  1. Back and Close both went to Home, instead of returning to the previous screen.
  2. The ID-number button moved forward with the field empty.
  3. The “:(” face is read by screen readers as “colon, parenthesis”.
  4. An account with no points saw the same screens as one with points, with no notice or nudge to earn.
  5. “Click” in a touch app.
  6. The selection changed color and the text turned white when tapping the button.

Two redesign screens, as they arrived

Fixing screen by screen would solve the symptom, but the same mistake would come back on the next screen. So the fix became a system.

02

Every visual decision became a token, and the component only reads the token.

Three layers, from the raw value to the name a screen uses.

Insight

“Screens use the name of the role, never the raw value. If the brand changes, only the value changes.”

  1. coreorange#F2A545

    The theme’s raw value. No screen uses it directly.

  2. semanticinteractive-fill-loud

    The role: fill of the primary button, the active segment and the selected chip.

  3. componentButton

    Reads only the semantic token. Changing the brand never touches it.

03

Four failures became rules, and each rule became a token or a line of copy.

Before and after, rule by rule.

Primary button label

Show my QR2.05:1
Show my QR7.07:1

A white label on orange is 2.05:1 and fails contrast. The primary button now uses a navy label, 7.07:1.

Link text color

View statement#DD8613
View statement#B35400 · 5.02:1

The oranges used for text in Figma (#DD8613, #F36208, #E8823F) fail contrast. Links now use orange-deep, 5.02:1 on the background.

Empty search

:(read aloud: “colon, parenthesis”

We couldn’t find “hard glass”

Check the spelling or see the full list.

See all materialsMaterials we don’t accept

The face was read as “colon, parenthesis”. Now the search shows the searched word, suggests checking the spelling and links to the full list.

Action verb

Click Recycle to schedule
Tap Recycle to schedule

On mobile there is no “click”. The content rule is “tap”, “you” and “participant” instead of “user”.

07

Each component’s contract says when to use it, when never to, and who checks it.

A real example: the Button.

Use for

An action button in five emphases (loud, dark, quiet, transparent, destructive).

Never

Two loud buttons on the same screen, or changing color or radius through className. Never white text on orange.

I wrote the AGENTS.md, the decision map and the composition rules so any AI (Claude, Claude Design, Figma AI) can use the system without inventing variants. There are 13 automatic checks, with a report.
